# Upstream source-bundle manifests

Unmodified copies of `SOURCES.json` and `SOURCE-SHA256SUMS` from `orbit-store-1.3.5-source-bundle.zip`
(release v1.3.5, bundle sha256 `c0fe51d94b199daa77b620b5d596afc13b77902076db313891885d0e54339858`).

They list the exact third-party source archives (SDKs, OpenSSL, curl, libmicrohttpd, libarchive, 7-Zip, ps5-opengl, ...)
with their URLs and SHA-256 values that the PS5 binaries are linked from. Orbit Store is GPL-3.0-or-later; anyone who
distributes binaries built from this fork must offer the corresponding source, which includes those archives. The
archives themselves are not copied here: fetch them from the upstream release's source bundle (verify with
`SOURCE-SHA256SUMS`) and offer them alongside any binary release.
